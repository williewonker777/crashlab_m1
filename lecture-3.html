?

모터에 ‘여기로 가’라고 어떻게 말하나?

CONCEPT

위치·속도·토크

  • 위치: 어디까지
  • 속도: 얼마나 빠르게
  • 토크: 얼마나 세게

CONCEPT

PID

  • 목표−현재 = 오차
  • P·I·D로 오차 해석
  • 출력으로 차이 축소

BUILD

BUILD 1 / 2
  • 목표 근처에서 진동

BUILD

BUILD 2 / 2
  • 부드럽게 목표 수렴

CONCEPT

관절 한계

  • 관절마다 허용 범위
  • 상한·하한 밖은 위험
  • 명령 전 범위 확인

QUESTION

?

바퀴 두 개로 어떻게 회전하나?

CONCEPT

차동 구동

  • 같은 속도: 직진
  • 속도 차이: 회전
  • v와 ω로 움직임 표현

CONCEPT

/cmd_vel 한 줄의 의미

  • linear.x: 앞뒤 속도
  • angular.z: 회전 속도
  • 두 값으로 평면 이동

QUESTION

?

관절 각도를 알면 손끝 위치를 알 수 있나? 반대는?

CONCEPT

정기구학

  • 관절 각도 → 손끝 위치
  • 한 방향 계산
  • 현재 자세 확인

CONCEPT

역기구학

  • 손끝 위치 → 관절 각도
  • 답이 여러 개 가능
  • 한계와 충돌 고려

CONCEPT

작업공간

  • 닿는 곳과 못 닿는 곳
  • 링크 길이가 범위 결정
  • 경계에서 여유 감소

CONCEPT

특이점

  • 팔을 다 편 자세
  • 일부 방향 통제 상실
  • 급격한 관절 속도
