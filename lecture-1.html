로보틱스 기초 · ROS2 · 개발환경

01

QUESTION

?

로봇은 자기 손이 어디 있는지 어떻게 알까?

CONCEPT

링크와 관절

  • 링크는 뼈, 관절은 마디다.
  • 관절 하나가 움직임 한 축을 만든다.
  • 베이스 좌표축도 함께 보자.

CONCEPT

자유도

  • 관절이 늘면 움직일 방향도 는다.
  • 1자유도는 한 축으로만 돈다.
  • 6자유도면 공간 자세까지 잡는다.

CONCEPT

좌표계가 필요한 이유

  • 같은 점도 기준이 바뀌면 달라진다.
  • 좌표계는 위치와 방향을 함께 갖는다.
  • 변환은 두 기준의 말을 번역한다.

BUILD

TF 트리

BUILD 1 / 3
  • 모든 좌표는 월드에서 시작한다.

BUILD

TF 트리

BUILD 2 / 3
  • 베이스를 잇자 로봇 위치가 보인다.

BUILD

TF 트리

BUILD 3 / 3
  • 변환을 이으면 손끝까지 찾을 수 있다.

CONCEPT

센서는 각자 다른 것을 잰다

  • 카메라는 색과 모양을 본다.
  • LiDAR는 거리를 바로 잰다.
  • IMU는 기울기와 가속도를 느낀다.
  • 엔코더는 축이 돈 만큼 센다.

COMPARE

카메라 vs LiDAR

카메라

  • 색과 질감을 함께 볼 수 있다.
  • 어두워지면 특징을 놓치기 쉽다.

LiDAR

  • 거리를 바로 재서 오차가 작다.
  • 유리나 반사면은 놓칠 수 있다.

QUESTION

?

노드 100개가 서로 데이터를 주고받으려면?

CONCEPT

ROS2 = 이름으로 주고받기

  • 노드는 저마다 한 역할을 맡는다.
  • 토픽 이름만 같으면 서로 연결된다.
  • 보내는 쪽과 받는 쪽은 독립적이다.

BUILD

토픽

BUILD 1 / 3
  • 토픽은 새 값을 계속 흘려보낸다.
  • 센서처럼 자주 바뀌는 값에 맞다.

BUILD

서비스

BUILD 2 / 3
  • 서비스는 한 번 묻고 답을 받는다.
  • 설정처럼 금방 끝나는 일에 맞다.

BUILD

액션

BUILD 3 / 3
  • 액션은 오래 걸리는 일을 맡는다.
  • 중간 진행률과 결과도 돌려준다.

GUIDE

셋을 언제 쓰나

토픽센서처럼 계속 보내는 값에 쓴다.
서비스금방 끝나는 요청과 응답에 맞다.
액션긴 작업의 진행률과 결과도 보낸다.
