# 덱 미리보기

슬라이드를 headless Chrome으로 찍어 직접 본다. 고치기 전에 **반드시 현재 상태를 먼저 본다.**

## 사용

```bash
tools/shot.sh lecture-1 3            # 3번 슬라이드, 1920x1080
tools/shot.sh lecture-1 all          # 전체 슬라이드
tools/shot.sh lecture-2 7 1280 720   # 해상도 지정
tools/shot.sh index full             # 페이지 전체 스크롤
```

결과는 `.shots/<page>-<NN>-<WxH>.png`. Read 도구로 열어 확인한다.
로컬 서버(127.0.0.1:8823)는 스크립트가 알아서 띄운다.

## 볼 때 기준

프로젝터 강의용이다. 1920×1080에서 판단한다.

- 뒷자리에서 읽히는가 — 본문 34px, 다이어그램 라벨 20px 이상
- 다이어그램이 화면의 주인공인가 — 텍스트가 그림보다 크면 실패
- 슬라이드당 불릿 4개 × 25자 한도를 지키는가
- 여백이 답답하지 않은가, 요소가 화면 밖으로 나가지 않는가
- 색은 한양 블루 #1D2475 / 에이로봇 그린 #75B446 안에서만

## 고친 뒤

같은 슬라이드를 다시 찍어 before/after를 비교한다. 찍지 않고 "고쳤다"고 하지 않는다.
