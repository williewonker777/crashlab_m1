SEMESTER GOAL

이번 학기 목표

학기말에는 시험 대신 실제 로봇으로 픽앤플레이스를 한다.

COURSE FORMAT

13차시를 팀 단위로 진행

  • 9월 11일부터 12월 18일까지 매주 금요일에 진행한다.
  • 한 차시는 4시간이고, 학기 전체로는 52시간이다.
  • 5~6명이 한 팀을 이루고 전체 5팀으로 운영한다.
  • 9월 25일과 10월 9일은 공휴일로 휴강한다.

TWO TRACKS

소프트웨어와 기구 설계를 함께 진행

소프트웨어 트랙

  • ROS2와 Isaac Sim 환경을 구축한다.
  • 주행 · VSLAM · VLA를 직접 개발한다.
  • 노트북과 서버에서 결과를 검증한다.

기구 설계 트랙

  • Creo로 그리퍼 요구조건을 정한다.
  • 부품 · 구동부 · 어셈블리를 설계한다.
  • 차시별 피드백으로 최종 CAD를 확정한다.

ROADMAP

강의 · 자율개발 · 실물 전환 순으로 진행

기초 강의 네 번이 끝나면 남은 기간은 팀 개발과 검증에 쓴다.

SCOPE

환경은 제공하고, 핵심 기능은 팀이 개발

수업에서 제공

  • Isaac Sim과 ROS2 Docker 환경
  • 시뮬 · 실물 데이터 수집 파이프라인
  • ALICE M1 제어 인터페이스

팀이 직접 개발

  • VSLAM · 내비게이션
  • VLA 학습 · 추론 · Headless 렌더링
  • 그리퍼 CAD · 에셋 · 실물 장착

TEAM SERVER

팀별 서버는 팀이 직접 운영

  • 10월 30일까지 시뮬레이션 VLA 학습을 시작한다.
  • 11월 27일까지 실물 데이터 학습을 시작한다.
  • 사용하지 않는 인스턴스는 중지해 비용을 관리한다.

MIDTERM · 11/13

중간평가는 두 환경에서 진행

VSLAM수업 시간에 팀별 노트북으로 맵 작성과 웨이포인트 주행을 실시간 평가한다.
VLA팀별 Vast.ai 서버에서 Headless 인퍼런스를 실행하고 렌더링한 영상으로 평가한다.
정확도웨이포인트 통과와 그리퍼 픽앤플레이스 성공 여부를 확인한다.
수행 시간성공한 시도의 미션 완료 시간을 함께 측정한다.

SIM TO REAL

시뮬레이션에서 실제 로봇으로

시뮬레이션과 실물의 차이는 실물 데이터를 다시 학습시켜 줄인다.

REAL ROBOT · 11/20

실물 실습은 로테이션으로 운영

  • 모든 팀이 먼저 안전교육과 M1 시연을 함께 본다.
  • 팀별 슬롯에서 그리퍼를 장착하고 실물 데이터를 수집한다.
  • 수업 시간 외 M1 사용은 지정된 시간에 예약제로 운영할 예정이다.

READY TO START

9월 11일까지
준비할 것

  1. 환경팀별 노트북 사양을 확인하고 ROS2 · Isaac Sim 환경을 준비한다.
  2. 팀5~6인으로 팀을 구성해 전체 5개 팀이 되도록 한다.
