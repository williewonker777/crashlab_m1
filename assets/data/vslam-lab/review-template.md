# Visual SLAM 학생 검증 기록

검증자가 직접 확인한 파일·행·픽셀·관측값으로 판정한다.
에이전트의 실행 보고를 받은 뒤 학생이 검사하고, 통과한 단계의 산출물을 다음 단계에 사용한다.
수정이 필요하면 같은 입력과 검사 항목으로 다시 확인한다.

## 실습 1 · RGB-D 입력

- 사용한 원본 입력·결과 파일:
- 직접 확인한 세 픽셀의 위치·원본 깊이·표시값:
- 선택한 CSV 3행·시각 차이 재계산값(ms):
- 30쌍 수집·무효 깊이 처리 확인:
- 학생 판정(통과 / 수정 필요)과 근거:
- 수정 요청·재검증 결과:

## 실습 2 · 특징점 대응

- 사용한 영상 두 장의 번호·시각:
- 직접 확인한 대응 5쌍의 번호·판단 근거:
- 검산한 한 점의 K·이전 픽셀·Z·계산한 XYZ·CSV 값:
- 깊이 픽셀을 0으로 바꾼 복사본·재실행 명령·해당 대응의 처리:
- 학생 판정(통과 / 수정 필요)과 근거:
- 수정 요청·재검증 결과:

## 실습 3 · 이동량과 궤적

- 동일 영상 반복 검사 명령·상대 이동(m)·회전(deg):
- 직접 관찰한 이동 방향·궤적의 축·단위:
- 단색으로 바꾼 복사본의 프레임 번호:
- 해당 프레임의 status·reason·직전/현재 자세:
- 학생 판정(통과 / 수정 필요)과 근거:
- 수정 요청·재검증 결과:

## 실습 4 · 키프레임 지도

- 키프레임 5개의 번호·시각·선택 이유:
- 지도에서 직접 살펴본 벽·어긋남과 원인:
- 이동 검사를 위해 선택한 키프레임 번호:
- 지도 x 방향 0.10 m 이동 전후의 점 좌표·다른 점군의 변화:
- 원래 자세·입력으로 복원했는지 확인:
- 학생 판정(통과 / 수정 필요)과 근거:
- 수정 요청·재검증 결과:

## 실습 5 · 루프 클로저 검증

- 직접 선택한 두 키프레임·같은 구조물·대응 5쌍의 관찰:
- 정상/섞은 대응의 입력 경로·재실행 명령:
- 두 검사의 대응 수·지지점 수·비율·채택/기각:
- 상대 자세의 방향·값·그래프에 추가할 관측:
- 학생 판정(통과 / 수정 필요)과 근거:
- 수정 요청·재검증 결과:

## 실습 6 · 궤적과 지도 보정

- 전후 입력·제약·가중치·첫 자세·지역 점군 대조:
- 직접 고른 루프 제약과 관측한 상대 위치:
- 자세가 예측한 상대 위치·직접 계산한 잔차·CSV 값:
- 새 터미널에서 직접 실행한 명령·입력 경로:
- 재실행한 J·루프 잔차·LOST 수·지도 확인:
- 학생의 최종 판정과 근거:
- 수정 요청·재검증 결과:

## 수정 요청 기록 형식

실습 번호 / 파일·행·픽셀 / 기대한 결과 / 직접 확인한 값 / 수정할 범위 / 재검증할 항목을 지정한다.
에이전트는 해당 단계의 변경점과 재실행 결과를 제시하고 학생의 다음 지시를 기다린다.
