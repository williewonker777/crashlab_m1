인식과 해석에서 행동 출력까지 하나의 흐름

CONCEPT · POLICY

정책: 관측과 명령에서 행동으로

VLA는 매 순간의 관측과 명령을 받아 다음 행동을 고르는 정책이다.

  1. 관측 oₜ · 지금의 상황

    카메라 영상과 관절 각도 같은 로봇 상태다. 무엇이 보이고 로봇이 어떤 자세인지를 담는다.

  2. 명령 l · 사람이 준 작업

    작업을 설명하는 문장이다. 한 에피소드 동안 보통 바뀌지 않는다.

  3. 행동 aₜ · 다음 순간의 목표

    관절 목표각이나 손끝 이동량이다. 강의 ②의 제어기가 이 값을 목표로 따라간다.

정책 π(aₜ | oₜ, l): 관측과 명령이 주어졌을 때의 행동 분포. VLA는 이 함수를 하나의 신경망으로 학습한다.

정책: 관측과 명령을 다음 행동으로 바꾸는 함수

CONCEPT

기존 방식과의 차이

  • 모듈형은 단계마다 사람이 규칙과 인터페이스를 정한다.
  • VLA는 영상·명령에서 행동까지 한 모델로 학습한다.
  • 모듈형은 원인 추적이 쉽고, VLA는 새 물체·표현에 유연하다.
  • 두 방식 모두 마지막 제어 단계는 그대로 둔다.

COMPARE

VLA의 강점과 한계

강점

  • 처음 보는 물체·문장에도 의미를 연결한다.
  • 명령 문장만 바꿔 여러 작업을 수행한다.
  • 공개 모델을 미세조정해 바로 시작할 수 있다.

한계

  • 새로운 동작은 로봇 데이터에서만 배운다.
  • 큰 모델은 느리다. RT-2(파라미터 550억 개, 55B)는 1~3 Hz였다.
  • 성공률을 높여도 안전을 보장하지는 않는다.

COMPARE

모방학습 vs 강화학습

모방학습

  • 전문가 시연을 그대로 모사한다.
  • 양질의 시연 데이터가 많을수록 유리하다.
  • VLA 학습의 기본이며 행동 복제라고도 한다.

강화학습

  • 시행착오로 누적 보상을 최대화한다.
  • 보상 설계가 잘못되면 의도와 다른 정책이 학습된다.
  • 최근에는 시연으로 배운 VLA를 다듬는 데 쓴다.

CONCEPT · BEHAVIOR CLONING

행동 복제와 누적 오차

시연을 따라 하는 정책은 작은 실수 뒤의 상황을 배운 적이 없다.

  1. 행동 복제 · Behavior Cloning

    시연에서 얻은 관측–행동 쌍을 지도학습으로 맞춘다. VLA 학습의 기본 방식이다.

  2. 분포 이동 · 오차의 누적

    조금 벗어난 상태는 학습 데이터에 없어 다음 행동도 틀리기 쉽다. 강의 ③의 드리프트처럼 오차가 쌓인다.

  3. 완화 방법

    다양한 시작 조건, 실수 뒤 복구하는 시연, 사람이 개입한 기록, 행동 묶음 예측을 사용한다.

토큰: 모든 입력을 같은 형식으로

영상·문장·로봇 상태를 한 줄의 토큰으로

GUIDE · TOKEN

토큰을 만드는 부품

토큰(Token)모델이 한 칸씩 읽는 입력 조각이다. 문장·영상·로봇 상태가 모두 토큰이 되어 한 줄로 이어진다.
벡터(Vector)순서가 정해진 숫자 목록이다. 토큰 하나는 벡터 하나가 되며, PaliGemma에서는 숫자 2048개다.
토크나이저(Tokenizer)문장을 사전에 있는 조각으로 자르고 번호를 붙인다. PaliGemma는 ‘빨간 컵을 집어’를 띄어쓰기를 포함해 7조각으로 자른다.
임베딩(Embedding)조각 번호를 벡터로 바꾸는 표다. 번호마다 숫자 목록이 있고, 그 값은 학습으로 정해진다.
비전 인코더(Vision Encoder)영상을 작은 정사각형 조각으로 나눠 조각마다 벡터를 만드는 신경망이다. 224×224 영상은 조각 256개다.
트랜스포머(Transformer)토큰끼리 서로 얼마나 참고할지 계산해 정보를 섞는 신경망이다. 이 계산 층을 여러 겹 쌓는다.

토큰은 원래 문장 조각을 부르던 말이다. 영상·상태도 같은 줄에서 읽으므로 토큰이라 부른다. 문장은 토크나이저로 조각·번호를 만들고, 영상·상태는 비전 인코더와 선형 변환으로 벡터를 만든다.

CONCEPT · LINEAR PROJECTION

선형 변환: 곱하고 더해 길이 맞추기

길이가 다른 숫자 목록을 모델이 쓰는 길이로 바꾸는 가장 단순한 계산이다.

  1. 계산 · 곱하고 더하기

    출력마다 가중치를 입력에 곱해 모두 더한다. 같은 점수에 대학마다 다른 비율을 곱해 환산 점수를 내는 계산과 같다.

  2. 쓰임 · 길이 맞추기

    π0·SmolVLA는 관절 상태를 선형 변환으로 토큰 하나로 만든다. PaliGemma는 비전 인코더의 숫자 1152개를 2048개로 맞춘다.

  3. 학습 · 가중치는 데이터로

    가중치는 사람이 정하지 않고 학습으로 정해진다. 관절값 8개를 숫자 1024개로 바꾸면 곱할 가중치만 8,192개다.

곱셈과 덧셈만 쓰기 때문에 선형이라 부른다. 신경망은 사이에 곡선을 만드는 계산을 끼워 복잡한 관계를 배운다.

곱셈과 덧셈으로 숫자 목록의 길이를 맞추는 변환

ARCHITECTURE · ACTION MODULE

행동 전문가와 확산 트랜스포머

둘 다 VLM이 읽은 영상·문장 정보를 참고해 행동 묶음을 만드는, 행동 전용의 작은 트랜스포머다.

π0 · 행동 전문가

π0가 붙인 이름이다. 한 트랜스포머에서 영상·문장은 VLM 가중치, 상태·행동은 작은 행동 전문가가 계산한다. 입력별 전문가가 맡는 전문가 혼합(MoE · Mixture of Experts)에서 온 이름이다.

GR00T N1 · 확산 트랜스포머

DiT(Diffusion Transformer)는 확산 모델의 잡음 다듬기를 트랜스포머로 계산하는 구조다. 2022년 이미지 생성용으로 나왔다. GR00T N1은 별도 DiT가 VLM 토큰을 참고하며, 플로 매칭으로 학습한다.

따로 두는 이유 · π0는 영상·문장 쪽 키·값을 저장하고 행동 전문가만 10번 재계산한다. RTX 4090에서 전체 73 ms 중 행동 10단계는 27 ms다. 로봇 토큰에 별도 가중치를 쓰자 성능도 올랐다고 보고했다.

확산은 잉크가 퍼지는 현상에서 온 이름이다. 잡음을 섞는 과정을 거꾸로 배운다. 뒤의 플로 매칭과 같은 학습법은 아니다.

상황을 읽는 VLM과 행동을 만드는 작은 트랜스포머의 분업

ARCHITECTURE · ACTION SPACE

행동 공간: 무엇을 출력하나

행동 벡터의 의미·범위·주기를 먼저 정해야 학습 데이터와 제어기가 맞물린다.

  1. 표현 · 관절 또는 손끝

    관절 목표각은 제어기에 바로 들어간다. 손끝 변화량은 IK(역기구학)로 관절각을 다시 구해야 한다.

  2. 정규화 · 범위 맞춤

    차원마다 단위와 범위가 다르다. 학습 데이터의 평균·표준편차나 백분위 같은 분위수로 비슷한 범위에 맞춘다.

  3. 주기 · 기록과 실행의 일치

    데이터를 기록한 주기와 실행 주기를 같게 둔다. 다르면 같은 행동이 다른 속도로 실행된다.

CONCEPT · MULTIMODALITY

평균 행동의 함정

같은 상황에서 시연이 두 갈래로 나뉘면, 평균을 내는 학습은 둘 다 아닌 행동을 만든다.

  1. 다봉 분포 · 정답이 여럿

    왼쪽으로 돌아가는 시연과 오른쪽으로 돌아가는 시연이 모두 올바른 상황이다.

  2. 평균의 문제

URDF · BUILD 1

조립도 기반 fixed joint 작성

WRIST1 아래 −73 mm 위치에 WRIST2 배치 · Z축 기준 +90° 회전

<joint name="l_wrist2" type="fixed">
  <origin xyz="0 0 -0.073"
          rpy="0 0 1.57079632679"/>
  <parent link="left_arm_link_7"/>
  <child link="left_wrist2_link"/>
</joint>

실제 URDF의 l_wrist2 발췌. 부모·자식 링크 선언은 생략했다.

  1. 73 mm → 0.073 m

    부모의 −Z 방향이므로 xyz의 z에 −0.073을 기록한다.

  2. 90° → 1.5708 rad

    URDF의 rpy에는 각도를 rad로 기록한다. 이 모델은 +90°를 사용한다.

  3. fixed · 자유도 없는 고정 연결

    WRIST2는 손목에 고정된 부품이다. 별도의 모터가 달린 회전관절이 아니다.

조립 위치는 origin, 운동 방식은 joint type으로 구분

URDF · BUILD 2

회전관절의 축과 한계 설정

WRIST2 아래 93.5 mm 위치에서 INPUT 관절 프레임의 X축 회전

  1. revolute · 범위가 있는 회전

    lower·upper는 rad 단위다. 1.3125 rad는 약 75.2°다.

  2. axis · 회전의 양의 방향

    오른손 법칙으로 확인한다. 실제 +90° 손목 조립 후에는 부모 손목 기준 축도 달라진다.

  3. effort·velocity · 모델의 한계 필드

    회전관절에서는 N·m와 rad/s를 사용한다. 기록된 값이 장비의 안전 허용값을 보장하지는 않는다.

<joint name="l_gripper_input" type="revolute">
  <origin xyz="0 0 -0.0935" rpy="0 0 0"/>
  <parent link="left_wrist2_link"/>
  <child link="left_gripper_input_link"/>
  <axis xyz="1 0 0"/>
  <limit lower="0.0" upper="1.3125"
         effort="1000" velocity="3.0"/>
</joint>

실제 URDF 발췌. effort=1000은 파일의 값이며 실기 구동 권장값이 아니다.

관절별 움직임으로 축·부호·범위 확인

실제 링크의 형상·충돌 구조를 간추렸다. 두 링크 완성 URDF는 원본 URDF 옆에 놓고 meshes/를 함께 사용한다.

    이 파일은 URDF 옆 meshes/를 참조한다. URDF만 복사하면 형상이 빠진다.

  2. 메시 단위 확인

  3. 메시 원점 확인

    메시 원점과 링크 원점이 다르면 visual origin을 조정한다. 조립도 치수와 함께 비교한다.

    이 XLSX의 단위는 질량 kg, COM m, 관성 kg·m²다. 메시와 함께 0.001을 다시 곱하지 않는다.

  1. body · 부품의 위치와 방향

    worldbody 아래에 부모·자식 body를 중첩한다. joint가 없는 자식 body는 고정된다.

  2. geom · 형상과 충돌

    mesh asset을 참조한다. 시각용 geom과 접촉용 geom을 나눌 수 있다.

  3. 단위 · compiler의 각도 단위 확인

    이 MJCF는 angle="degree"다. URDF의 1.5708 rad가 euler="0 0 90"에 대응한다.

<compiler angle="degree" meshdir="meshes"/>

      pos="0 0 -0.073" euler="0 0 90">

실제 MJCF의 속성을 간추린 발췌. inertial과 그리퍼 자식 body는 생략했다.

    이 파일은 joint equality 12개를 쓰며 connect 폐루프 제약은 없다. ctrl 제한도 자동으로 생기지 않는다.
